# User Experience Redesign of CieID App
> **UUXD Final Project — A.Y. 2025/2026**
> *HPHP Initiative (Help People Help People) — Client: Istituto Poligrafico e Zecca dello Stato*

## Project overview
**CieID v.2** is the final result of a redesign of the user experience of the CieID application, the official app of the Istituto Poligrafico e Zecca dello Stato that allows access to the online services of the Public Administration using the Electronic Identity Card. 

This version handles the simplification of the **PIN recovery process** and the subsequent **third-level access**, which involves **NFC scanning** of the CIE (Italian electronic identity card).

To test the new user experience, you can access via this [link](https://www.figma.com/proto/DTPnEq1DOoK0RPujd9aMxF/CieID-v.2?node-id=1-1834&p=f&t=eLTBE2Yyq22DZGAz-1&scaling=scale-down&content-scaling=fixed&page-id=0%3A1&starting-point-node-id=1%3A1834).
